# ATM手数料ナビ（非公式）

みずほ銀行のキャッシュカードで、いま一番安く引き出せるATMと手数料を、曜日と時刻から計算するツールです。

- 対象ATM：セブン銀行、イーネット（ファミリーマートなど）、みずほ銀行・イオン銀行、ゆうちょ銀行
- みずほ銀行のシステムメンテナンス予定も表示します

## 注意

個人が作成した非公式のツールで、記載の金融機関とは関係ありません。手数料は公開情報をもとにした目安です。実際の金額はATMの画面で確認してください。

情報の最終確認日：2026年10月14日

## 更新するとき

手数料やメンテナンス予定は `index.html` の中の `ATMS`（手数料）と `MAINT`（メンテナンス予定）を書き換えます。書き換えたら、ページ内の「最終確認日」も更新してください。
